XAMPP

¿Qué es XAMPP?

XAMPP es una distribución de Apache que contiene MariaDB, PHP y Perl. Es una solución de desarrollo que permite probar tu trabajo (páginas web, programación, etc) en tu propio ordenador sin necesidad de internet.

Componentes principales:

  • Apache (servidor web)
  • MariaDB/MySQL (base de datos)
  • PHP (lenguaje de programación)
  • Perl (lenguaje de programación)
  • phpMyAdmin (administración de bases de datos)

Ventajas:

  • Fácil de instalar y usar
  • Perfecto para desarrollo local
  • Multiplataforma (Windows, Linux, Mac)
  • Configuración mínima requerida
